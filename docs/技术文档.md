# 研时 · 技术文档

考研各科学习时长统计 App（Android，纯本地）

- 版本：v0.1
- 日期：2026-10-25
- 仓库：https://github.com/gyd258/kaoyan-time （Private）
- 应用名：研时
- 包名：`com.gyd.kaoyantime`（安装后不可更改）

---

## 1. 目标与范围

### 1.1 目标

在手机上独立、离线地记录考研各科目的学习时长，按日/周/月/全程汇总，并记录每天对学习方法的个人理解（不含具体考研知识）。

### 1.2 做

- 自定义科目与科目下的任务，完全从零自建，无预置数据
- 每天手动填写学习时长，也可用计时器计时；两者统一为记录条目
- 今日 / 本周 / 本月 / 全程四个维度的汇总，含 7 日柱状图与科目占比环图
- 每科目设置目标总时长，显示进度
- 考研考试日期倒计时
- 每天每科可写多条笔记，纯文本，支持关键词搜索
- 数据导出 CSV / JSON，可导入 JSON 恢复
- 深色 / 浅色跟随系统

### 1.3 不做

- 不做账号体系、云同步、多设备同步
- 不做定时推送提醒（Android 后台限制多，可靠性差）
- 不做科目下再分章节的第三层结构
- 不做番茄钟式的强制 25 分钟分段、白名单、专注锁机
- 不接任何统计或广告 SDK，不申请网络权限

## 2. 技术选型

| 项 | 选择 | 理由 |
|---|---|---|
| 框架 | Flutter（stable 渠道），Dart 3 | 单套代码出 APK，UI 一致，生态成熟 |
| 本地数据库 | `sqflite` + `path_provider` | 关系型查询方便做汇总，轻量无需代码生成 |
| 状态管理 | `provider` + `ChangeNotifier` | 规模小，避免引入重型状态框架 |
| 图表 | `fl_chart` | 柱状图、环图开箱可用，纯本地绘制 |
| 文件导入导出 | `file_picker` | 使用系统文件选择器（SAF），Android 10+ 无需存储权限 |
| 日期时间格式化 | `intl` | 中文日期显示与 CSV 时间格式 |
| 目标平台 | Android 6.0（API 23）及以上 | 覆盖面足够，避开更老的兼容问题 |
| 屏幕方向 | 仅竖屏 | 单列布局，减少适配 |
| 网络 | 不声明 INTERNET 权限 | 完全离线，数据不出手机 |

不引入：`firebase`、任何云服务 SDK、`flutter_local_notifications`。

## 4. 数据模型

SQLite，库名 `yanshi.db`，`version = 1`。所有时间戳为毫秒。

### 4.1 表结构

```sql
CREATE TABLE subjects (
  id             INTEGER PRIMARY KEY AUTOINCREMENT,
  name           TEXT    NOT NULL,
  color          INTEGER NOT NULL,              -- ARGB 颜色值
  target_minutes INTEGER NOT NULL DEFAULT 0,    -- 0 表示未设目标
  archived       INTEGER NOT NULL DEFAULT 0,    -- 1 表示已归档
  sort_order     INTEGER NOT NULL DEFAULT 0,
  created_at     INTEGER NOT NULL
);

CREATE TABLE tasks (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  subject_id INTEGER NOT NULL REFERENCES subjects(id),
  name       TEXT    NOT NULL,
  archived   INTEGER NOT NULL DEFAULT 0,
  sort_order INTEGER NOT NULL DEFAULT 0,
  created_at INTEGER NOT NULL
);
CREATE INDEX idx_tasks_subject ON tasks(subject_id);

CREATE TABLE time_entries (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  subject_id INTEGER NOT NULL REFERENCES subjects(id),
  task_id    INTEGER REFERENCES tasks(id),      -- 可为空：只记科目不选任务
  day        TEXT    NOT NULL,                  -- 学习日 yyyy-MM-dd
  minutes    INTEGER NOT NULL,
  source     TEXT    NOT NULL,                  -- manual | timer
  note       TEXT,                              -- 备注，最长 200 字
  started_at INTEGER,                           -- 计时开始时间戳
  ended_at   INTEGER,                           -- 计时结束时间戳
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL
);
CREATE INDEX idx_entries_day     ON time_entries(day);
CREATE INDEX idx_entries_subject ON time_entries(subject_id);

CREATE TABLE notes (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  day        TEXT    NOT NULL,                  -- 学习日 yyyy-MM-dd
  subject_id INTEGER NOT NULL REFERENCES subjects(id),
  content    TEXT    NOT NULL,
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL
);
CREATE INDEX idx_notes_day     ON notes(day);
CREATE INDEX idx_notes_subject ON notes(subject_id);

CREATE TABLE settings (
  key   TEXT PRIMARY KEY,
  value TEXT NOT NULL
);

CREATE TABLE timer_state (
  id             INTEGER PRIMARY KEY CHECK (id = 1),  -- 单行
  subject_id     INTEGER,
  task_id        INTEGER,
  started_at     INTEGER,          -- 本次运行片段的开始时刻
  accumulated_ms INTEGER NOT NULL DEFAULT 0,
  running        INTEGER NOT NULL DEFAULT 0,
  note           TEXT
);
```

### 4.2 settings 键

| key | 值 |
|---|---|
| `exam_date` | `2026-12-19` 形式的学习日 |
| `schema_version` | `1` |
| `last_export_at` | 上次导出时间戳（仅用于提示） |

主题直接跟随系统，不存设置项。

### 4.3 关键约束

- 科目、任务删除一律改为 `archived = 1`，历史条目与笔记保留。
- 归档科目不出现在录入选择器，但汇总与笔记中仍可查。
- 同一天同一科可有多条条目与多条笔记，不做唯一限制。
- `minutes` 取值范围 1–1440；`note` 最长 200 字。

## 5. 学习日与跨零点规则

用户选择**凌晨 4 点分界**：

```
studyDay(t):
  若 t 的本地小时 < 4，则该学习日 = 日期(t - 1 天)
  否则             学习日 = 日期(t)
格式：yyyy-MM-dd
```

- 手动录入：用户选择的日期即学习日，不再二次偏移。
- 计时器：按**开始时刻**计算学习日；跨过 4 点或跨过午夜都整段计入开始学习日，不拆分。
- 汇总、柱状图、笔记分组全部以 `day` 字段为准。
- 每次查询前以设备本地时区计算，不存 UTC 日字符串到查询逻辑中。

## 6. 页面与交互规格

### 6.1 底部导航

四个 Tab：**今日 / 汇总 / 笔记 / 设置**。图标 + 文字，选中主色。

### 6.2 今日页

自上而下：

1. 日期行：`‹ 10月25日 周六 ›`，点中间日期回到今天；右到不能超过今天。
2. 倒计时条：`距考试还有 55 天`，未设置考试日期时显示「设置考试日期」入口。
3. 今日总时长：大号数字 `3 小时 25 分`，下方小字「共 4 条记录」。
4. 科目卡片列表（仅未归档科目）：每张卡片显示科目名、今日时长、本周时长、目标进度条与百分比。点击卡片进入该科目今日条目列表。
5. 今日条目列表：时间线样式，每行显示科目色点、任务名（无任务时显示科目名）、分钟数、来源标记（手动/计时）、备注；右滑删除（带确认），点击编辑。
6. 右下角悬浮按钮「+」：打开录入面板。
7. 有计时在运行时，底部显示计时条（见 6.4），此时悬浮按钮上移。

空状态：没有任何科目时，页面中央显示「还没有科目」+ 按钮「新建科目」；有科目但当日无记录时显示「今天还没有记录」。

### 6.3 录入面板（底部弹层）

- 科目选择：横向可滚动的颜色胶囊，单选。
- 任务选择（可选）：该科目下的任务下拉，含「不指定任务」。
- 时长：数字输入框（分钟），下方三个快捷按钮 `+15` `+30` `+60`，点击在现有值上累加。
- 日期：默认选中当前学习日，可点开日期选择器补录往日，不能选未来。
- 备注（可选）：单行文本框，200 字限制。
- 底部「保存」按钮；编辑已有条目时多一个「删除」。
- 保存后关闭弹层，今日页数据即时刷新。

校验：未选科目或分钟数不在 1–1440 时，保存按钮置灰。

### 6.4 计时器

入口在今日页悬浮按钮长按，或「+」面板中的「开始计时」标签页。

状态：未开始 → 运行中 → 已暂停 → 结束生成条目。

- 开始：选择科目与任务（可带备注），写入 `timer_state`，记录 `started_at`。
- 运行中：计时条显示 `01:23:45`，按钮「暂停」「结束」。
- 暂停：把本段时长累加到 `accumulated_ms`，`running = 0`，清空 `started_at`。
- 继续：重新记录 `started_at`，`running = 1`。
- 结束：生成一条 `source = timer` 的条目，`minutes = round(总时长秒 / 60)`，总时长不足 1 分钟时按 1 分钟记；`started_at` / `ended_at` 取首段开始与结束时刻；`day` 取首段开始时刻的学习日。之后清空 `timer_state`。
- 恢复：App 启动或回到前台时若 `running = 1`，显示时长按 `accumulated_ms + (now - started_at)` 计算，不依赖后台常驻服务，锁屏不受影响。
- 异常：若恢复时 `now - started_at` 超过 12 小时，弹窗询问「保留已计时的 12 小时」或「丢弃本次计时」，避免忘记结束时产生离谱数据。
- 修改系统时间导致的负数时长一律按 0 处理。

### 6.5 汇总页

顶部范围切换：`今日` `本周` `本月` `全程`。本周以周一为起点。

内容：

1. 总时长大数字 + 记录条数 + 日均时长（今日范围不显示日均）。
2. 近 7 天柱状图：横轴为学习日（MM/dd），纵轴为分钟；今天高亮；无数据日显示 0，柱高为 0 时不显示数值标签。
3. 科目占比环图：当前范围内各科目时长占比，中心显示总时长；无数据时显示「暂无数据」。
4. 科目明细列表：科目名、时长、占比、目标进度（仅全程范围显示目标进度，其他范围显示该范围时长）。
5. 归档科目单独折叠区「已归档」，默认收起。

### 6.6 笔记页

- 顶部：搜索框（按内容关键词，LIKE 模糊匹配）+ 科目筛选胶囊。
- 列表按学习日倒序分组，组头显示日期与当日笔记数；每条显示科目色点、科目名、内容两行截断、时间。
- 点击条目进入编辑；新建按钮打开编辑面板。
- 编辑面板：科目（必选）、日期（默认当前学习日，可选往日）、多行文本、保存/删除。
- 搜索无结果时显示「没有匹配的笔记」。

### 6.7 设置页

分组列表：

- **备考**：考试日期（点击选日期）、剩余天数展示。
- **科目与任务**：进入科目管理（新增/改名/改色/设目标小时/归档/恢复/排序），进入任务管理（按科目查看，新增/改名/归档）。
- **数据**：导出 CSV、导出 JSON 备份、导入 JSON（二次确认，覆盖当前数据）、清空数据（二次确认，需输入「清空」）。
- **外观**：跟随系统（默认，不提供手动切换，保持最简）。
- **关于**：版本号、包名、数据仅存本机提示。

### 6.8 通用交互

- 所有删除操作二次确认；导入与清空额外加重提示。
- 列表为空有对应文案，不使用插图。
- 加载中不显示骨架屏（本地查询毫秒级）。

## 8. 导出与导入

### 8.1 CSV（明细，给 Excel 看）

- 文件名：`yanshi_entries_yyyyMMdd_HHmm.csv`
- 编码 UTF-8 带 BOM，逗号分隔，字段含逗号或引号时用双引号包裹。
- 列：`学习日, 科目, 任务, 分钟, 来源, 备注, 创建时间`
- 来源显示「手动」/「计时」；任务为空时留空；创建时间 `yyyy-MM-dd HH:mm`。
- 导出内容为全部时间条目，按学习日升序。

### 8.2 JSON（全量备份）

```json
{
  "app": "yanshi",
  "schemaVersion": 1,
  "exportedAt": 1761400000000,
  "subjects": [
    { "id": 1, "name": "数学", "color": 4282671359, "targetMinutes": 30000, "archived": 0, "sortOrder": 0, "createdAt": 1761000000000 }
  ],
  "tasks": [
    { "id": 1, "subjectId": 1, "name": "张宇1000题", "archived": 0, "sortOrder": 0, "createdAt": 1761000000000 }
  ],
  "timeEntries": [
    { "id": 1, "subjectId": 1, "taskId": 1, "day": "2026-10-25", "minutes": 90, "source": "manual", "note": "", "startedAt": null, "endedAt": null, "createdAt": 1761400000000, "updatedAt": 1761400000000 }
  ],
  "notes": [
    { "id": 1, "day": "2026-10-25", "subjectId": 1, "content": "今天发现先做题再回看讲义效率更高。", "createdAt": 1761400000000, "updatedAt": 1761400000000 }
  ],
  "settings": { "exam_date": "2026-12-19" }
}
```

- 导入为**覆盖模式**：先校验 `app` 与 `schemaVersion`，再在事务内清空并写入，失败整体回滚。
- 导入前弹窗提示「导入会覆盖当前全部数据，建议先导出备份」。
- 通过系统文件选择器读写，App 不申请存储权限。

## 9. 构建与发布

### 9.1 签名

- 在本地用 `keytool` 生成一次 `upload-keystore.jks`（有效期 10000 天），放在 `android/app/upload-keystore.jks`，随代码提交进私有仓库。
- `android/key.properties` 同样提交（私有仓库，个人使用）：

```
storePassword=<密码>
keyPassword=<密码>
keyAlias=upload
storeFile=upload-keystore.jks
```

- `android/app/build.gradle` 读取 `key.properties` 配置 release 签名。
- 签名固定后，新版本 APK 可直接覆盖安装，数据库不丢。
- 若日后更换签名文件，必须先导出 JSON 备份、卸载旧版、装新版、再导入。

### 9.2 GitHub Actions

`.github/workflows/build-apk.yml`：

```yaml
name: build-apk

on:
  push:
    tags: ['v*']
  workflow_dispatch:

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: '17'
      - uses: subosito/flutter-action@v2
        with:
          channel: stable
          cache: true
      - run: flutter pub get
      - run: flutter build apk --release
      - uses: actions/upload-artifact@v4
        with:
          name: yanshi-apk
          path: build/app/outputs/flutter-apk/app-release.apk
      - uses: softprops/action-gh-release@v2
        if: startsWith(github.ref, 'refs/tags/')
        with:
          files: build/app/outputs/flutter-apk/app-release.apk
```

### 9.3 版本号

- `pubspec.yaml` 中 `version: 1.0.0+1`，`+` 后为 versionCode。
- 发版流程：改版本号 → 提交 → 打 tag `v1.0.0` → Actions 自动构建并把 APK 挂到 Release。
- 手机安装：在该 Release 页面下载 `app-release.apk`，允许「安装未知来源应用」后安装。

### 9.4 首次可安装性检查

- `flutter build apk --release` 产物可直接安装，无需 Android SDK 在本机（由 Actions 完成）。
- 若 Actions 中 Flutter 版本升级导致构建失败，把 `channel: stable` 改为固定版本号即可复现问题。

## 10. 验收清单

1. 首次打开：无任何预置科目，今日页显示空状态与「新建科目」。
2. 新建科目「数学」、任务「张宇1000题」，录入 90 分钟，今日总时长为 1 小时 30 分。
3. 手动 +15 两次，当日该科目累计增加 30 分钟，条目列表新增两条。
4. 计时：开始 → 锁屏 3 分钟 → 回到 App，显示时长包含锁屏时间；结束生成 3 分钟记录。
5. 暂停后关闭 App 再打开，计时条仍显示暂停状态与已累计时长；继续后正常累计。
6. 23:50 开始计时、00:20 结束，该记录归属 23:50 所在学习日（因凌晨 4 点分界，00:20 也属于前一天）。
7. 01:00 手填记录并选择今日，归入前一日学习日；界面分组显示一致。
8. 修改某条历史记录分钟数后，今日、本周、科目进度同步变化。
9. 科目目标 30 小时，累计超过后进度条显示 100% 且标注实际时长。
10. 未设置考试日期时显示设置入口；设置后显示剩余天数，跨日后自动减 1。
11. 汇总页四个范围切换数值正确；近 7 天柱状图与每日明细一致；无数据时显示占位文案。

## 11. 风险与对策

| 风险 | 对策 |
|---|---|
| 数据只在本机，清数据/换机会丢 | 设置页导出入口常驻；导入导出写进验收；不提供自动清空 |
| 忘记结束计时导致超长记录 | 恢复时超过 12 小时弹窗确认 |
| 系统时间被手动调整导致负数时长 | 负数按 0 处理，并在结束生成条目时下限 1 分钟 |
| Actions 拉取 Flutter 失败或版本漂移 | 固定 stable 版本号重试；必要时改回固定版本 |
| 包名不可改，后期想改只能重装 | 现定 `com.gyd.kaoyantime`，后续不再变更 |
| 以后加功能需改表结构 | `settings.schema_version` + `onUpgrade` 迁移，避免删库 |
